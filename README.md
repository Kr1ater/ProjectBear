# Dead Air — лут, инвентарь и разборка

Тестовое задание, вариант 1 - Лут, инвентарь и разборка

- **Unity:** 6000.3.6f1 (Unity 6.3 LTS), URP, Cinemachine 3.
## Управление

| Действие                 | Клавиша                  |
| ------------------------ | ------------------------ |
| Ходьба                   | WASD                     |
| Камера                   | Мышь                     |
| Камера на другое плечо   | X                        |
| Подобрать предмет        | E                        |
| Инвентарь                | Tab                      |
| Разобрать выбранный хлам | X или кнопка «Разобрать» |
| Выбросить одну штуку     | G или кнопка «Выбросить» |

## Предметы

Каждый предмет — это ScriptableObject `ItemDefinition`. В нём записано всё, что нужно знать о предмете: название, описание, иконка, вес одной штуки, сколько штук помещается в одну стопку, как его подбирать (сам или по E), на что он разбирается и как выглядит на земле. Все предметы лежат в `Assets/_Project/Data/Items`, их там 11.

У каждого предмета есть категория:

- **Consumable** — расходники: медпакеты, кислородные картриджи;
- **RepairResource** — ресурсы для ремонта: болты, изолента, проводка;
- **Junk** — хлам, который можно разобрать: старая рация, сломанный насос;
- **Weapon** — оружие: карабин.

По категориям работают вкладки в инвентаре, а разбирать можно только хлам.

Чтобы добавить новый предмет: ПКМ в папке `Data/Items` → **Create → Dead Air → Item Definition**, заполнить поля и поставить префаб предмета на сцену. На префабе должен быть компонент `WorldItem` и коллайдер-триггер на слое `Loot`.

## Как устроен инвентарь

Инвентарь построен на стаках. Внутри это просто список стопок (`ItemStack`), где каждая стопка — пара «какой предмет и сколько штук». У каждого предмета свой предел стопки (`maxStack`): например, болтов в одну стопку влезает много, а оружия всегда лежат по одному.

Когда в инвентарь что-то кладут, он сначала докладывает в уже начатые стопки этого предмета, а когда они заполнятся — заводит новые. При удалении штуки забираются с конца списка, и пустая стопка исчезает. Вес инвентаря — это сумма весов всех стопок.

Ограничение одно — вес, по умолчанию 15. Если предмет не влезает, игрок видит, почему: «Перегруз: Карабин — нужно 6.0, свободно 2.4», а шкала веса мигает. Если из кучки влезает только часть, игрок забирает сколько может, остальное остаётся лежать.

Сам инвентарь (`Inventory`) — обычный C#-класс. После любого изменения он отправляет событие `OnChanged`, и интерфейс по нему перерисовывается. Разборкой занимается отдельный `SalvageService`: он убирает одну штуку хлама и кладёт вместо неё детали. Если детали не влезут, не меняется ничего.

## Что ещё есть в игре

- **Два вида подбора.** Мелочь вроде болтов подбирается сама, когда подходишь вплотную. Крупные предметы берутся по E — тот, что ближе к центру экрана.
- **Подсветка лута.** Над предметами рядом появляются янтарные скобки.
- **Анимации.** Подобранный предмет не пропадает, а улетает в рюкзак и уменьшается. Выброшенный — вылетает из рюкзака и падает перед игроком.
## Структура кода

```
Assets/_Project/Scripts/
  Items/      описание предметов (ScriptableObject)
  Inventory/  инвентарь, стопки и разборка — чистый C#
  World/      предмет на земле и его полёт в рюкзак
  Player/     ввод, движение, камера, поиск и подбор лута, выброс
  UI/         HUD, скобки над лутом, лента сообщений, экран инвентаря
```
